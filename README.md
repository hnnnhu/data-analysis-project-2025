## 🧠 Giới thiệu

Dự án này được thực hiện trong khuôn khổ môn **Phân tích Dữ Liệu**, với mục tiêu giúp sinh viên:
- Làm quen với quy trình **xử lý, làm sạch và phân tích dữ liệu thực tế**.  
- Ứng dụng các thư viện **Pandas, NumPy, Matplotlib, Seaborn** để trực quan hóa dữ liệu.  
- Tạo ra **các báo cáo và biểu đồ** giúp rút ra insight có ý nghĩa từ dữ liệu.  

Dự án được phát triển bằng **Python** trong môi trường **Jupyter Notebook** và quản lý mã nguồn bằng **GitHub**.

## 📈 Quy trình phân tích dữ liệu

1. **Thu thập dữ liệu:** Lấy dữ liệu từ file hoặc nguồn công khai.  
2. **Khám phá dữ liệu (EDA):** Phân tích tổng quan, tìm hiểu cấu trúc dữ liệu.  
3. **Làm sạch dữ liệu:** Xử lý giá trị thiếu, loại bỏ outlier, chuẩn hóa định dạng.  
4. **Trực quan hóa:** Biểu đồ, heatmap, histogram để minh họa mối quan hệ.  
5. **Phân tích & Kết luận:** Tìm insight và trình bày báo cáo kết quả.
