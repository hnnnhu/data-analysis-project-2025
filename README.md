## 🧠 GIỚI THIỆU ĐỀ TÀI

**Phân tích dữ liệu (Data Analysis)** là quá trình thu thập, làm sạch, xử lý, và trực quan hóa dữ liệu nhằm rút ra thông tin hữu ích hỗ trợ ra quyết định.  

Dự án này được thực hiện trong khuôn khổ môn học *Phân tích Dữ Liệu*, với mục tiêu:
- Ứng dụng quy trình **phân tích dữ liệu thực tế** bằng ngôn ngữ **Python**.  
- Làm quen với các thư viện phổ biến trong **khoa học dữ liệu (Data Science)**.  
- Trình bày quy trình phân tích theo **chuẩn khoa học – có hệ thống, có minh chứng và kết luận rõ ràng**.  

---

## 🎯 MỤC TIÊU NGHIÊN CỨU

1. Áp dụng quy trình khoa học dữ liệu (Data Analysis Workflow) vào bộ dữ liệu thực tế.  
2. Sử dụng **Pandas**, **NumPy**, **Matplotlib**, **Seaborn** để phân tích và trực quan hóa.  
3. Xây dựng báo cáo phân tích thể hiện mối quan hệ, xu hướng, và insight quan trọng.  
4. Tăng cường kỹ năng làm việc nhóm và quản lý phiên bản bằng **Git & GitHub**.

## 🧩 PHƯƠNG PHÁP NGHIÊN CỨU

Dự án tuân theo **quy trình phân tích dữ liệu 5 bước** như sau:

| Giai đoạn | Nội dung chính | Công cụ sử dụng |
|------------|----------------|----------------|
| **1. Thu thập dữ liệu** | Lấy dữ liệu từ file CSV, Excel hoặc nguồn mở | Python, Pandas |
| **2. Làm sạch dữ liệu (Data Cleaning)** | Xử lý giá trị thiếu, dữ liệu nhiễu, chuẩn hóa định dạng | Pandas, NumPy |
| **3. Khám phá dữ liệu (EDA)** | Thống kê mô tả, kiểm tra phân phối dữ liệu | Pandas, Matplotlib |
| **4. Trực quan hóa dữ liệu** | Vẽ biểu đồ, biểu đồ tương quan, heatmap | Seaborn, Matplotlib |
| **5. Phân tích & Kết luận** | Diễn giải ý nghĩa và rút ra insight | Python Notebook |

🧩 VÍ DỤ MINH HỌA

Ví dụ dưới đây minh họa cách áp dụng quy trình phân tích dữ liệu vào một bài toán cụ thể.

Bước 1 – Thu thập dữ liệu:
Nhập dữ liệu từ tệp CSV, Excel hoặc nguồn công khai.

Bước 2 – Làm sạch dữ liệu:
Xử lý các giá trị thiếu, loại bỏ dữ liệu không hợp lệ, chuẩn hóa định dạng.

Bước 3 – Khám phá dữ liệu (EDA):
Tính toán thống kê mô tả, kiểm tra phân phối và mối tương quan giữa các biến.

Bước 4 – Trực quan hóa:
Vẽ biểu đồ phân phối, biểu đồ tán xạ (scatter plot), heatmap để phát hiện xu hướng.

Bước 5 – Phân tích & Kết luận:
Đưa ra nhận xét, rút ra insight và đề xuất hướng phân tích mở rộng.
